# Project-Feasibility-study-on-antenna-design-using-LArge-Language-Model-LLM-

This project focuses on the design, simulation, and analysis of three practical antenna systems used in modern wireless communication and networking applications. The work includes an LTE microstrip patch antenna for indoor coverage, a 2.4 GHz RF energy harvesting rectenna for IoT devices, and a 500 MHz loop antenna for underground pipe and cable detection.

The antennas were designed using analytical calculations and simulated using CST Studio Suite, OpenEMS, and Python-based analysis tools. The project demonstrates antenna optimisation, RF performance evaluation, and real-world networking applications while exploring important concepts such as bandwidth, gain, efficiency, and signal propagation.
